================================================================================
                    DEPLOYMENT GUIDE - QUICK START
================================================================================

Your AI Content Creator is ready to deploy! Follow these simple steps:

================================================================================
STEP 1: DEPLOY BACKEND TO RENDER (5 minutes)
================================================================================

1. Go to: https://render.com
2. Sign up with GitHub
3. Click "New +" → "Web Service"
4. Connect repository: AI-Content-Creator-2026
5. Configure:
   - Name: ai-content-creator-backend
   - Branch: ai-cc
   - Root Directory: backend
   - Build: pip install -r ../requirements.txt
   - Start: python start_server.py
   
6. Add Environment Variables (click "Advanced"):
   OPENAI_API_KEY=sk-proj-your-key
   MONGODB_URI=mongodb+srv://your-connection-string
   JWT_SECRET_KEY=your-secret-32-chars-minimum
   PORT=8000
   FLASK_ENV=production
   
7. Click "Create Web Service"
8. Wait 2-5 minutes for deployment
9. COPY YOUR BACKEND URL: https://your-app.onrender.com

📖 Detailed guide: RENDER_BACKEND_DEPLOYMENT.md

================================================================================
STEP 2: DEPLOY FRONTEND TO NETLIFY (2 minutes)
================================================================================

1. Go to: https://netlify.com
2. Sign up with GitHub
3. Click "Add new site" → "Import from Git"
4. Connect repository: AI-Content-Creator-2026
5. Configure:
   - Branch: ai-cc
   - Base directory: react-frontend
   - Build: npm run build
   - Publish: react-frontend/build
   
6. Add Environment Variables:
   REACT_APP_API_URL=https://your-backend.onrender.com/api
   REACT_APP_GOOGLE_CLIENT_ID=761738188033-2qj8ulfak02gosv5esoll637eqa7ql1i.apps.googleusercontent.com
   
7. Click "Deploy site"
8. Wait 2-3 minutes
9. YOUR APP IS LIVE! 🎉

📖 Detailed guide: DEPLOYMENT.md

================================================================================
STEP 3: TEST YOUR DEPLOYMENT (2 minutes)
================================================================================

1. Test Backend:
   https://your-backend.onrender.com/api/health
   Should return: {"status": "healthy"}

2. Test Frontend:
   https://your-app.netlify.app
   Should load the landing page

3. Test Features:
   ✓ Register new user
   ✓ Login
   ✓ Generate content (English)
   ✓ Generate content (Marathi)
   ✓ Check content history
   ✓ Update settings

📖 Full checklist: BACKEND_DEPLOY_CHECKLIST.md

================================================================================
TROUBLESHOOTING
================================================================================

Backend won't start:
  → Check environment variables are set correctly
  → Check MongoDB connection string
  → Check MongoDB IP whitelist (0.0.0.0/0)
  → View logs in Render dashboard

Frontend can't connect:
  → Check REACT_APP_API_URL is correct
  → Check backend is running (health endpoint)
  → Check CORS is enabled in backend

Slow response:
  → Normal for Render free tier (30-60 sec first request)
  → Upgrade to Starter plan for always-on
